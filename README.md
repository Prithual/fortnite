# 🎮 Fortnite 3D Web Battle Royale (Multiplayer)

A full-featured 3D Fortnite Battle Royale web game built with **Three.js**, **WebSockets**, and modern **JavaScript**.

---

## 🚀 Quick Start Instructions

### 1. Requirements
- Node.js (version 18 or newer)

### 2. Installation
Open a terminal in this folder and run:
```bash
npm install
```

### 3. Start the Game
Run:
```bash
npm start
```
Then open your browser at:
👉 **http://localhost:3000**

---

## 🕹️ Controls

- **Move**: `W`, `A`, `S`, `D`
- **Sprint**: `Shift` (Hold)
- **Jump / Deploy Glider / Jump from Bus**: `Space`
- **Crouch**: `C`
- **Aim Down Sights (ADS / Sniper Scope)**: `Right Mouse Button` (Hold)
- **Shoot / Mine / Build / Turbo Build**: `Left Mouse Button` (Click or Hold)
- **Reload**: `R`
- **Emote Dance**: `B`
- **Pick Up Loot / Open Chest**: `E`
- **Weapons Hotbar (1–5)**:
  - `1`: Harvesting Tool (Pickaxe)
  - `2`: Assault Rifle (Scar)
  - `3`: Pump Shotgun
  - `4`: Bolt-Action Sniper Rifle
  - `5`: Small Shield Potion / Medkit
- **Building Hotbar**:
  - `Q`: Wall
  - `E`: Ramp / Stairs
  - `F`: Floor
  - `R`: Roof / Cone
- **Unlock Mouse Cursor**: `Esc`

---

## 👥 Multiplayer / Playing with Friends
1. Start the server (`npm start`).
2. Open `http://localhost:3000` in your browser.
3. Share the room link (or open a second tab/window on `http://localhost:3000`).
4. Both players will drop together from the Battle Bus into the match!
